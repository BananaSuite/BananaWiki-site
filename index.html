Features

Optional features are off by default, and an administrator can turn them on. Turning a feature off keeps its data.

Writing

  • Markdown editor with a toolbar and a live preview
  • Drafts saved as you type, and a warning when two people save the same page
  • Images you can crop, resize and align in the editor; attachments and embedded video
  • Full-text search over the pages you may read
  • Pages exported as Markdown or PDF; bulk Markdown import and export
  • A page builder for layouts made of blocks (optional)

History and review

  • Every revision kept, compared and restorable
  • An audit log of sign-ins, role changes and other administrative actions
  • One list of requests waiting for a decision, with email notices when mail is set up
  • Protected pages, and check-outs that reserve a page for one editor (optional)
  • Edits proposed by readers, applied after review (optional)
  • Deleted pages kept for 48 hours (optional)

People and access

  • Roles from user to owner, plus roles you build from single permissions
  • Read and write access per category
  • Invite codes, open sign-up with an end date and approval of new accounts
  • Private by default, with optional public reading
  • Two-step verification with an authenticator app, optionally required for administrators
  • Scheduled deletion of pages and accounts, and temporary promotions (optional)

Working together

  • Kanban boards with checklists, due dates, comments, attachments and history
  • Canvases with shapes, notes and links to pages, and a text outline for screen readers
  • Direct messages and group chats, where members can block someone and report a message
  • Announcement banners across the site
  • Member profiles with badges and a contribution chart
  • A contributor leaderboard (optional)

Reading and learning

  • Pages read aloud with Piper voices, after you install the voices
  • Quizzes and polls on a page, with points and a limit on attempts
  • Badges given by hand or earned automatically
  • Difficulty labels on pages
  • Personal settings for text size, spacing, contrast and a dyslexia-friendly font, under Appearance in the account menu

Running the wiki

  • Interface in English, Italian and German, and you can upload more languages
  • Light and dark themes in colours you choose
  • A guided tour for new members, and an easy mode that hides the advanced tools
  • Personal data export for every member, and whole-site export and import for administrators
  • REST API with scoped tokens and webhooks (optional)
  • Custom pages at an address you choose (optional)
  • Pages shared read-only with other BananaWiki installations (optional)

Run it yourself

The source code is on GitHub under the GNU AGPL, and you can use it for personal, educational and commercial purposes. If you run a modified version that other people use over a network, the licence requires you to make its source code available to them.

  1. A Linux server

    Clone the repository and check out its newest release tag, as the README shows. sudo ./banana install --mode wiki --domain wiki.example.org installs the wiki as a system service and sudo bananawiki proxy --install configures Caddy for HTTPS. The deployment guide covers updates and backups.

  2. Docker Compose

    One wiki behind Caddy with automatic HTTPS, from the compose.yaml in the repository.

  3. Any computer with Python 3.11 or newer

    The quick start below runs a wiki on your own computer so you can try it out. The getting started guide has more details.

  4. One computer, no server

    BananaWiki Desktop runs a wiki from a small window on Windows, macOS or Linux, which works well for a classroom or an office. It’s built from the same source code, but it doesn’t include read aloud.

  5. A hosting service of your own

    The same code runs the hosting platform, which creates a wiki for each customer. It needs a Linux x86_64 server with Docker, including BuildKit (docker buildx), and Caddy. We recommend XFS with project quotas, which the platform uses automatically to give each wiki a hard storage limit. On other filesystems, the app checks uploads and the portal checks each wiki’s size every 5 minutes. That’s enough if all the wikis are yours, but for a public service you should use XFS.

Quick start

git clone https://github.com/BananaSuite/BananaWiki.git
cd BananaWiki
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
bananawiki serve
# in a second terminal (same folder and venv),
# print the token the setup page asks for
bananawiki setup-token

Then open http://127.0.0.1:5001 and enter the token to create the first account. On Windows, activate the environment with .venv\Scripts\activate. For read aloud, also run python -m pip install -e '.[tts]' and install ffmpeg. This server is only meant for trying BananaWiki out. For a wiki that other people use, follow the deployment guide.

Where it came from

Luca Zani started BananaWiki on 20 February 2026 for a team that needed a wiki for its work. Development sped up in June, and BananaWiki grew into the wiki and hosting platform it is today. It has been free software since September 2026, maintained by Luca Zani and contributors.

Three smaller projects grew alongside it. BananaChat started as BananaAI and gives a group one shared chat with local and hosted language models. BananaVibe keeps coding agents working on a long task until it’s done and reviewed. BananaGit is our fork of Gitea, with the same look and its own updater. The About page tells the full story.

Questions

Is it free software?

Yes. BananaWiki is licensed under the GNU AGPL version 3, and you can use it for personal and commercial purposes. The hosted service runs the same code you can download.

Can I move my wiki off the hosted service later?

Yes. An administrator can export the whole wiki and import it into their own BananaWiki installation. Moving your wiki to your own server explains the steps.

What do visitors see when a hosted wiki is stopped?

They see a short page at the wiki’s own address that says whether the wiki is paused, suspended, expired or starting. Visitors aren’t redirected to the hosting portal.

Does the hosted service show ads or sell data?

No. There’s no advertising, and user data is never sold.

Who runs the hosted service?

Luca Zani runs it, using the same code you can download. Sign-up isn’t always open, and this page says so when it’s closed.

Do readers need an account?

Yes, by default, because wikis are private. Public reading is optional, and on the hosted service it’s enabled on request.

Does it include AI features?

No, the wiki doesn’t include a language model. BananaChat is a separate project for running models on your own hardware.

Who do I write to?

For the hosted service, email contact@bananawiki.com. For the software, open an issue on GitHub. Please report security problems privately, as described in the security policy.
