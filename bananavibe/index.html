A sister project of BananaWiki

Keep coding agents working until the job is really done

Claude Code, Codex and OpenCode finish one task and hand control back. BananaVibe is a small command-line supervisor that restarts them on your goal for hours, days or weeks, runs your checks, and has an independent reviewer audit the work before it counts as done.

Install BananaVibe See a real run

BananaVibe is free software under the GNU AGPL version 3. It has no model of its own: it runs the agents you’re already logged in to.

Features

It works with any project and any goal, such as new features, production readiness, refactoring, test coverage, migrations or documentation. One workspace can hold several repositories.

Long runs

  • Every session starts with a fresh context
  • Memory lives in files: the mission, a master plan, notes, a journal of handoffs and the Git history
  • Each session’s work is committed on a separate branch of each repository
  • Only you, or a budget you set, end a run

Verification

  • A claim of done is rejected while plan items are open or your checks fail
  • An independent reviewer, ideally a different model, audits the work against the mission
  • Findings go back to the workers
  • The run ends after enough approvals in a row, two by default

Limits and failures

  • Usage limits wait for the reset time, read from the agent’s own messages
  • Outages and crashes back off and retry, and work done before a failure is committed
  • With several agents, it fails over to one that’s available
  • A guardian process restarts the supervisor after a crash, a kill or a reboot

Watching and steering

  • A live full-screen dashboard with keys to pause, resume, message and ask
  • A chat that answers questions about the run and takes instructions
  • Messages that reach the running agent between its tasks, or at once
  • Optional notifications to a command or a webhook

Pausing and moving

  • Pause or stop now and continue later, with the interrupted session remembered
  • Change the mission or the settings while it runs
  • Export a run and import it on another machine, with a checksum verified on import
  • Open any past session in the agent’s own interface

Running it

  • Python’s standard library only, with nothing else to install
  • bananavibe doctor --live checks that every agent answers before a long run
  • Starts at boot and whenever the run is down, through systemd or cron
  • Old logs are compressed and pruned, and a full disk makes it wait, not fail

Install

You need at least one agent’s command-line tool, installed and logged in.

Install it

pipx install git+https://github.com/BananaSuite/BananaVibe

# or from a checkout, without installing anything
git clone https://github.com/BananaSuite/BananaVibe
cd BananaVibe
./scripts/install.sh

The script puts a bananavibe launcher in ~/.local/bin that runs the checkout directly.

Start a run

# in a repository, or a folder of repositories
bananavibe init --workers claude,codex --reviewer codex \
  --check "tests=pytest -q" --goal "Make this project production ready"
bananavibe doctor --live
bananavibe start

# later
bananavibe dashboard

Describe the mission and what done means in .bananavibe/GOAL.md before you start. The guide to writing goals and the configuration reference cover the rest.

Before you run it

Where should it run?

BananaVibe runs agents with every permission prompt turned off, because nobody is there to approve them. Run it on a dedicated server, a container or a throwaway virtual machine, never on your main account, and give it only the credentials it needs. The server guide describes a hardened setup.

Can agents push or deploy?

Agents are told not to push or deploy unless you allow it in the configuration. BananaVibe’s protections guard against mistakes, not against a deliberately hostile agent, so the isolation comes from the machine you give it.

Is BananaVibe an agent?

No. It makes no model API calls. It runs the agents’ own command-line tools with their own logins, and every session is an ordinary conversation of that agent.

Which subscriptions can I use?

Whatever login each tool has: a Claude subscription in Claude Code, a ChatGPT plan in Codex, or API keys. Each provider’s terms and usage policies apply. Use a Claude subscription only through Claude Code itself.

How it relates to BananaWiki

BananaVibe started in August 2026 as BananaAgent, to keep work on BananaWiki and BananaChat moving. It became a command-line tool with version 1.0 in October 2026.

It’s a separate program that works with any repository. Luca Zani created it and maintains it with contributors. The About page tells the full story.
