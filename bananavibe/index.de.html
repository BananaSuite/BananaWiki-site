Ein Schwesterprojekt von BananaWiki

Lass Coding-Agents arbeiten, bis die Aufgabe wirklich erledigt ist

Claude Code, Codex und OpenCode erledigen eine Aufgabe und geben die Kontrolle zurück. BananaVibe ist ein kleiner Supervisor für die Kommandozeile, der sie stunden-, tage- oder wochenlang wieder auf dein Ziel ansetzt, deine Prüfungen ausführt und die Arbeit von einem unabhängigen Reviewer kontrollieren lässt, bevor sie als erledigt gilt.

BananaVibe installieren Einen echten Lauf ansehen

BananaVibe ist freie Software unter der GNU AGPL Version 3. Es hat kein eigenes Modell: Es startet die Agents, bei denen du schon angemeldet bist.

Funktionen

Es funktioniert mit jedem Projekt und jedem Ziel, zum Beispiel neue Funktionen, Produktionsreife, Refactoring, Testabdeckung, Migrationen oder Dokumentation. Ein Arbeitsbereich kann mehrere Repositorys enthalten.

Lange Läufe

  • Jede Sitzung beginnt mit einem frischen Kontext
  • Das Gedächtnis liegt in Dateien: die Mission, ein Gesamtplan, Notizen, ein Journal der Übergaben und die Git-Historie
  • Die Arbeit jeder Sitzung wird auf einem eigenen Branch jedes Repositorys committet
  • Nur du oder ein Budget, das du festlegst, beendet einen Lauf

Prüfung

  • Meldet ein Agent die Arbeit als fertig, während Planpunkte offen sind oder Prüfungen fehlschlagen, wird das abgelehnt
  • Ein unabhängiger Reviewer, am besten ein anderes Modell, prüft die Arbeit gegen die Mission
  • Was er findet, geht zurück an die arbeitenden Agents
  • Der Lauf endet nach genügend Freigaben hintereinander, standardmäßig zwei

Limits und Fehler

  • Bei einem Nutzungslimit wartet es bis zur Rücksetzzeit, die es aus den Meldungen des Agents liest
  • Nach Ausfällen und Abstürzen versucht es mit wachsenden Pausen erneut, und die Arbeit vor dem Fehler wird committet
  • Mit mehreren Agents wechselt es zu einem, der verfügbar ist
  • Ein Wächterprozess startet den Supervisor nach einem Absturz, einem Kill oder einem Neustart wieder

Beobachten und steuern

  • Ein Live-Dashboard im Vollbild, mit Tasten zum Pausieren, Fortsetzen, Schreiben und Fragen
  • Ein Chat, der Fragen zum Lauf beantwortet und Anweisungen annimmt
  • Nachrichten, die den laufenden Agent zwischen seinen Aufgaben oder sofort erreichen
  • Optionale Benachrichtigungen an einen Befehl oder einen Webhook

Pausieren und umziehen

  • Pausiere oder stoppe sofort und mach später bei der unterbrochenen Sitzung weiter
  • Ändere die Mission oder die Einstellungen im laufenden Betrieb
  • Exportiere einen Lauf und importiere ihn auf einem anderen Rechner, mit einer Prüfsumme, die beim Import kontrolliert wird
  • Öffne jede frühere Sitzung in der Oberfläche des Agents

Betrieb

  • Nur die Standardbibliothek von Python, sonst ist nichts zu installieren
  • bananavibe doctor --live prüft vor einem langen Lauf, ob jeder Agent antwortet
  • Startet beim Hochfahren und immer, wenn der Lauf nicht läuft, über systemd oder cron
  • Alte Logs werden komprimiert und gelöscht, und bei voller Festplatte wartet es, statt zu scheitern

Installation

Du brauchst das Kommandozeilenwerkzeug mindestens eines Agents, installiert und angemeldet.

Installieren

pipx install git+https://github.com/BananaSuite/BananaVibe

# oder aus einem Checkout, ohne etwas zu installieren
git clone https://github.com/BananaSuite/BananaVibe
cd BananaVibe
./scripts/install.sh

Das Skript legt in ~/.local/bin einen Befehl bananavibe an, der den Checkout direkt ausführt.

Einen Lauf starten

# in einem Repository oder einem Ordner mit Repositorys
bananavibe init --workers claude,codex --reviewer codex \
  --check "tests=pytest -q" --goal "Make this project production ready"
bananavibe doctor --live
bananavibe start

# später
bananavibe dashboard

Beschreibe vor dem Start in .bananavibe/GOAL.md die Mission und was „fertig“ bedeutet. Die Anleitung zum Schreiben von Zielen (auf Englisch) und die Konfigurationsreferenz (auf Englisch) erklären den Rest.

Bevor du es startest

Wo sollte es laufen?

BananaVibe startet Agents mit abgeschalteten Berechtigungsabfragen, weil niemand da ist, der sie bestätigt. Lass es auf einem eigenen Server, in einem Container oder in einer Wegwerf-VM laufen, nie in deinem Hauptkonto, und gib ihm nur die Zugangsdaten, die es braucht. Die Server-Anleitung (auf Englisch) beschreibt eine gehärtete Einrichtung.

Dürfen Agents pushen oder deployen?

Den Agents wird gesagt, dass sie nicht pushen oder deployen sollen, solange du es in der Konfiguration nicht erlaubst. Die Schutzmechanismen von BananaVibe helfen gegen Fehler, nicht gegen einen absichtlich feindseligen Agent: Die Isolation kommt von dem Rechner, den du ihm gibst.

Ist BananaVibe ein Agent?

Nein. Es ruft keine Modell-APIs auf. Es startet die Kommandozeilenwerkzeuge der Agents mit deren eigenen Anmeldungen, und jede Sitzung ist eine gewöhnliche Unterhaltung dieses Agents.

Welche Abonnements kann ich nutzen?

Die Anmeldung, die das jeweilige Werkzeug hat: ein Claude-Abonnement in Claude Code, ein ChatGPT-Tarif in Codex oder API-Schlüssel. Es gelten die Bedingungen und Nutzungsrichtlinien jedes Anbieters. Nutze ein Claude-Abonnement nur über Claude Code selbst.

Wie es mit BananaWiki zusammenhängt

BananaVibe begann im August 2026 als BananaAgent, um die Arbeit an BananaWiki und BananaChat voranzubringen. Mit Version 1.0 wurde es im Oktober 2026 zu einem Werkzeug für die Kommandozeile.

Es ist ein eigenes Programm, das mit jedem Repository funktioniert. Luca Zani hat es entwickelt und pflegt es mit Mitwirkenden. Die Seite Über uns erzählt die ganze Geschichte.
