Un progetto affiancato a BananaWiki

Gitea per i tuoi progetti, con aggiornamenti che tornano indietro se falliscono

BananaGit è un servizio Git da installare sul tuo server, con repository, revisione del codice, segnalazioni, registro dei pacchetti e CI/CD. È un fork di Gitea con i colori di BananaSuite, e il suo aggiornamento verifica una release firmata, fa un backup e torna indietro se la nuova versione non parte.

Installazione

Provalo prima sul tuo computer. Un server richiede Linux su amd64 o arm64 con systemd, Git, un database PostgreSQL e Python 3.9 o successivo per l’aggiornamento.

Sul tuo computer

# Git, Go e Node.js con pnpm
git clone https://github.com/BananaSuite/BananaGit.git
cd BananaGit
TAGS="sqlite sqlite_unlock_notify" make build
./gitea web

Poi apri http://localhost:3000, lascia SQLite come database e registrati. Il primo account è l’amministratore, e tutto resta in quella cartella.

Su un server Linux

# dopo i passaggi di installazione del README
sudo bananagit-update check
sudo bananagit-update update

Il README (in inglese) prepara l’utente, le cartelle, il binario della release e il servizio. La guida agli aggiornamenti (in inglese) spiega ogni impostazione e che cosa fare se un aggiornamento fallisce. Per altre configurazioni, segui la guida all’installazione di Gitea (in inglese) con il binario di BananaGit. Se arrivi da Gitea, sostituisci il binario e tieni database e dati, come spiega la guida alla migrazione (in inglese).

Il legame con BananaWiki

Abbiamo creato BananaGit per ospitare i nostri progetti Git. Usa lo stesso logo con la banana di BananaWiki e BananaChat, e si installa separatamente da entrambi.

Le modifiche che non riguardano il nome, l’aspetto o l’aggiornamento di BananaGit vanno proposte a Gitea. La pagina Chi siamo racconta la storia degli altri progetti.
