Ein Schwesterprojekt von BananaWiki

Gitea für deine Projekte, mit einem Updater, der zurückrollt

BananaGit ist ein selbst gehosteter Git-Dienst mit Repositorys, Code-Review, Issues, Paketregistry und CI/CD. Es ist ein Fork von Gitea in den Farben von BananaSuite, und sein Updater prüft ein signiertes Release, legt ein Backup an und rollt zurück, wenn die neue Version nicht startet.

BananaGit installieren Was sich gegenüber Gitea ändert

BananaGit behält die MIT-Lizenz von Gitea. Es ist nicht Gitea und wird vom Gitea-Projekt nicht unterstützt oder empfohlen.

Installation

Probiere es zuerst auf deinem eigenen Computer aus. Ein Server braucht Linux auf amd64 oder arm64 mit systemd, Git, eine PostgreSQL-Datenbank und Python 3.9 oder neuer für den Updater.

Auf deinem Computer

# Git, Go und Node.js mit pnpm
git clone https://github.com/BananaSuite/BananaGit.git
cd BananaGit
TAGS="sqlite sqlite_unlock_notify" make build
./gitea web

Öffne dann http://localhost:3000, behalte SQLite als Datenbank und registriere dich. Das erste Konto ist der Administrator, und alles bleibt in diesem Ordner.

Auf einem Linux-Server

# nach den Installationsschritten im README
sudo bananagit-update check
sudo bananagit-update update

Das README (auf Englisch) richtet Benutzer, Verzeichnisse, die Release-Binärdatei und den Dienst ein. Die Update-Anleitung (auf Englisch) erklärt jede Einstellung und was zu tun ist, wenn ein Update fehlschlägt. Für andere Umgebungen folgst du der Installationsanleitung von Gitea (auf Englisch) mit der BananaGit-Binärdatei. Von Gitea aus tauschst du die Binärdatei und behältst Datenbank und Daten, wie die Migrationsanleitung (auf Englisch) erklärt.

Wie es mit BananaWiki zusammenhängt

Wir haben BananaGit gebaut, um unsere eigenen Git-Projekte zu hosten. Es nutzt dasselbe Bananen-Logo wie BananaWiki und BananaChat und wird getrennt von beiden installiert.

Änderungen, die nicht Name, Aussehen oder Updater von BananaGit betreffen, gehören zu Gitea. Die Seite Über uns erzählt die Geschichte der anderen Projekte.
